# Rekrafted v1.8 UAT Reports

This repository contains Playwright automation UAT test execution reports, logs, and artifacts for Rekrafted v1.8.

## Structure

- **`orderFullFillment/`**: Test execution reports and artifacts for Order Fulfillment test suites (`t0001` - `t0012`).
- **`siteAdmin/`**: Test execution reports and artifacts for Site Admin modules (Store Setup, Product Master, Testimonials, Theme Customization, etc.).
